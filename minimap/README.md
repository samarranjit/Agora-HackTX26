# Agora — Minimap

Standalone Phaser + React sketch of a top-down palace map. **Not used by the live adventure.** The frontend does not import this package.

## Run

```sh
npm ci
npm run dev
```

## Layout

```text
minimap/
├── index.html
├── package.json
├── src/
│   ├── main.jsx          React mount
│   ├── App.jsx           shell
│   └── PhaserGame.jsx    Phaser canvas
└── public/assets/        goblin, wolf, dragon, prince, princess
```
